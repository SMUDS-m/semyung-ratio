# 세명대 2027학년도 수시 지원 현황 추이

유웨이 경쟁률 페이지를 **매시간 자동 수집**해서 6개 학과의 지원 현황 변화를 그래프로 보여줍니다.

## 📊 그래프 보기

**<https://SMUDS-m.github.io/semyung-ratio/>**

선 끝에 각 학과의 **최신 경쟁률 숫자**가 표시됩니다. 6개 학과는 색과 **선 모양**으로 함께 구분해, 색각이상이나 흑백 인쇄에서도 구별됩니다. 학과별 선택, 시점별 상세 값(마우스 올리기), 표 보기를 지원하고, 화면 폭에 따라 글자 크기가 자동으로 조절됩니다.

**세 가지 보기**

| 모드 | 내용 |
|---|---|
| 경쟁률 | 전 전형 합산 정원내 경쟁률 |
| 지원자 수 | 정원내 지원인원 |
| 작년 대비 | 경쟁률 탭과 같은 선 + 작년 최종 위치(굵은 반투명 가로선) |

## 대상 학과

AI컴퓨터학부 · 스마트IT학부 · 전기전자공학과 · 건축학과 · 재난안전학과 · 보건안전공학과

## 데이터

| 파일 | 내용 |
|---|---|
| `data/ratio_history.csv` | 원본 시계열 (시점 × 학과) |
| `docs/data.js` | CSV에서 생성한 차트용 데이터 |
| `docs/index.html` | 차트 페이지 (의존성 없는 순수 HTML/SVG) |
| `docs/lastyear.js` | 작년 비교선 값 — 아래 주의사항 참고 |
| `docs/breakdown.js` | 현재 시점 스냅샷: 대학 전체 + 학과별 전형내역 (매 실행 갱신) |

CSV 컬럼: `collected_at`(페이지 기준시각, KST), `department`, `capacity`(정원내 모집인원), `applicants`(정원내 지원인원), `applicants_extra`(정원외 지원인원), `capacity_general`·`applicants_general`(학생부교과 일반전형 단독). 마지막 두 컬럼은 2026-09-09 17:00부터 기록돼 그 이전 행은 비어 있습니다.

## 사용법

```
python3 fetch_ratio.py            # 현재 현황 요약 출력
python3 fetch_ratio.py --detail   # 전형별 상세까지
python3 fetch_ratio.py --log      # 요약 + CSV 기록 + docs/data.js 갱신
python3 fetch_ratio.py --build    # 네트워크 없이 CSV -> docs/data.js 재생성
```

`--log`는 같은 기준시각이 이미 CSV에 있으면 건너뛰므로 여러 번 실행해도 중복되지 않습니다.

## 산출 방식

- **경쟁률 = 정원내 지원인원 ÷ 정원내 모집인원.** 페이지의 11개 전형에 흩어진 값을 학과 단위로 합산하며, 타일에 전형별 내역도 함께 표기합니다.
- **대학 전체 경쟁률**은 페이지 상단 '전형별 경쟁률 현황' 요약표를 합산해 제목 옆에 표시합니다.
- 정원외 전형(농어촌학생·특성화고교·기초생활수급자)은 모집인원이 `N명 이내`로 표기돼 분모를 만들 수 없어, 지원자 수만 `applicants_extra`로 따로 집계하고 경쟁률에서는 제외합니다.
- 수집 시각은 실행 시각이 아니라 **페이지가 표시하는 기준시각**입니다. 대학 측이 주기적으로 갱신하므로 실시간보다 1~2시간 늦을 수 있습니다.

## ⚠️ 작년 비교선에 대한 주의

`docs/lastyear.js` 의 작년 수치는 **검증되지 않은 참고치**입니다.

- **학생부교과 일반전형 단독** 값인데 올해 선은 전 전형 합산이라 **기준이 다릅니다.** 정확한 1:1 비교가 아니라 대략적인 참고선으로만 보세요. (참고용으로 올해 일반전형 단독 수치도 CSV에 함께 기록하고 있습니다.)
- 출처는 제3자 입시정보 사이트(학점나비) 한 곳이며, 대학 공식 발표나 대학어디가로 **교차 검증하지 못했습니다.** 대학어디가는 대학별 상위 10개 모집단위만 공개해 대상 학과가 포함되지 않았습니다.
- 학과 개편으로 이름이 바뀐 곳이 있습니다: AI컴퓨터학부(작년 컴퓨터학부), 보건안전공학과(작년 보건안전학과). 모집인원 구성이 달라졌을 수 있습니다.

공식 자료를 구하면 `docs/lastyear.js` 의 `ratio` 값을 고치고 `verified: true` 로 바꾸세요. 차트의 "미검증" 꼬리표가 자동으로 사라집니다.
