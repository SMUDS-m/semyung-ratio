# 세명대 2027학년도 수시 지원자 현황

유웨이 경쟁률 페이지를 **매시간 자동 수집**해서 6개 학과(AI융합대학)의 지원자 현황을 그래프로 보여줍니다.

## 📊 그래프 보기

**<https://SMUDS-m.github.io/semyung-ratio/>**

그래프 표시 구간은 **12시간 / 24시간 / 전체** 버튼으로 고를 수 있습니다(기본 12시간, 선택은 브라우저에 기억됩니다). 전체 이력은 `data/ratio_history.csv` 에 그대로 쌓입니다.

선 끝에 각 학과의 **최신 경쟁률 숫자**가 표시됩니다. 6개 학과는 색과 **선 모양**으로 함께 구분해, 색각이상이나 흑백 인쇄에서도 구별됩니다. 학과별 선택, 시점별 상세 값(마우스 올리기), 표 보기를 지원하고, 화면 폭에 따라 글자 크기가 자동으로 조절됩니다.

**세 가지 보기**

| 모드 | 내용 |
|---|---|
| 경쟁률 | **학생부교과 일반전형** 단독 경쟁률 (2026-09-09 17시부터 기록) |
| 지원자 수 | **정원내 + 정원외 전체** 지원인원 (2026-09-07 13:20부터 전 구간) |
| 작년 대비 | **정원내 전 전형** 경쟁률 + 작년 공식 최종 기준선(AI융합대학 2.32 / 대학 전체 4.45) |

상단 타일의 큰 숫자는 차트와 달리 **전 전형 합산 정원내 경쟁률**입니다(학과 대표값). 타일 아래 전형별 표에서 개별 전형을 볼 수 있고, 차트의 기준이 되는 **일반전형 행은 붉게 강조**됩니다.

제목 옆에는 **대학 전체**와 **AI융합대학**(= 대상 6개 학과 합계) 경쟁률을 함께 표시합니다.

## 사용법

```
python3 fetch_ratio.py            # 카톡용 메시지 출력 (재난안전학과 전형별)
python3 fetch_ratio.py --detail   # 전형별 상세까지
python3 fetch_ratio.py --log      # 요약 + CSV 기록 + docs/data.js 갱신
python3 fetch_ratio.py --build    # 네트워크 없이 CSV -> docs/data.js 재생성
```

`--log`는 같은 기준시각이 이미 CSV에 있으면 건너뛰므로 여러 번 실행해도 중복되지 않습니다.

카카오톡으로 보낼 학과는 `fetch_ratio.py` 의 `KAKAO_DEPT` 상수로 바꿉니다. CSV·그래프는 6개 학과 전체를 계속 수집합니다.

## 산출 방식

- **경쟁률 = 정원내 지원인원 ÷ 정원내 모집인원.** 페이지의 11개 전형에 흩어진 값을 학과 단위로 합산하며, 타일에 전형별 내역도 함께 표기합니다.
- **대학 전체 경쟁률**은 페이지 상단 '전형별 경쟁률 현황' 요약표를 합산해 제목 옆에 표시합니다.
- 정원외 전형(농어촌학생·특성화고교·기초생활수급자)은 모집인원이 `N명 이내`로만 공고됩니다. 타일의 전형별 표에서는 그 상한 `N`을 분모로 삼아 `≤N`으로 표기하므로, 표시된 경쟁률은 **하한값**입니다(실제 선발인원이 N보다 적으면 실제 경쟁률은 더 높습니다).
- 학과 대표 경쟁률과 그래프의 시계열에는 정원외를 넣지 않습니다(정원내 기준). 정원외 지원자 수는 CSV의 `applicants_extra`에 따로 쌓입니다.
- 수집 시각은 실행 시각이 아니라 **페이지가 표시하는 기준시각**입니다. 대학 측이 주기적으로 갱신하므로 실시간보다 1~2시간 늦을 수 있습니다.

## 작년 비교

제목 옆 **대학 전체 / AI융합대학**의 작년 수치는 세명대 입학처 배포 자료(「2027학년도 수시모집 지원현황」, 2026.9.11 09:00 기준)에서 옮긴 **공식 정원내 기준**입니다. 이 자료로 파서를 검증했고, 6개 학과의 모집인원·전형구조 22개 항목이 전부 일치했습니다.

### 「작년 대비」 탭의 기준선

입학처 자료에는 **학과별 작년 수치가 없습니다.** 「전년도 지원현황」 행은 대학 전체 × 전형별이고, 아래 표는 단과대학 단위입니다. 그래서 학과마다 각자의 작년 선을 그을 수 없습니다.

대신 **AI융합대학 2.32**(작년 정원내 최종)를 공통 기준선으로 두어, 각 학과가 작년 단과대학 수준을 넘었는지 보도록 했습니다. 보조선으로 대학 전체 4.45도 함께 표시합니다.

올해 선은 **정원내 전 전형 합산**이라 기준선과 산출 방식이 같습니다. 「경쟁률」 탭의 일반전형 기준과 다른 이유는, 올해 `인문계고교전형`·`특성화고교인재전형`이 신설되면서 작년 일반전형 정원이 쪼개져(대학 전체 1,095명 → 803명) 범위가 어긋나기 때문입니다.

입학처에서 학과별 작년 확정치를 받으면 `docs/lastyear.js` 에 추가해 학과별 선으로 바꿀 수 있습니다.
